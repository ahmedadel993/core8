# CORE8

CORE8 is a beverage brand.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app. The main page is in `src/app/page.tsx`.

## Build

```bash
npm run build
npm start
```

For more information about Next.js, see the [Next.js documentation](https://nextjs.org/docs).
